# 데이터 모델 초안

아직 데이터베이스는 구성되지 않았습니다. PostgreSQL/JPA 구현 시 아래 엔터티를 기준으로 권한 범위와 학습 이력을 분리합니다.

- `User`: 보호자 계정, 이메일, 암호 해시, 역할, 생성 시각
- `StudentProfile`: 보호자 외래 키, 이름/별칭, 1~3학년, 생성 시각
- `Question`: 유형, 학년, 문제 형식, 지문, 선택지, 정답, 설명, 검수 상태
- `QuestionAttempt`: 학생, 문제, 답, 정오, 소요 및 제출 시각
- `Writing`: 학생, 원문, 입력 방식(`KEYBOARD`/`HANDWRITING`), 작성 시각
- `WritingError`: 글, 원문 범위, 오답/정답 표현, 카테고리, 재시도 수, 힌트 단계, 해결 여부, 반복 여부
- `WeaknessProfile`: 학생과 카테고리별 정답률, 최근 오답, 반복 오답, 약점 점수 및 집계 시각
- `WeeklyReport`: 학생, 기간, 통계, 보호자 요약

학생은 보호자 이메일 가입을 요구하지 않고 보호자 계정에 연결된 프로필로 관리합니다. 글과 학습 이력 조회는 보호자 소유권을 서버에서 검증합니다.
